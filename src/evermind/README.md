# `evermind` package

Research package namespace. Foundation only — no implementation yet.

- `model/` — the adapted backbone and model architecture (future).
- `state/` — internal state representations and update mechanisms (future).
- `events/` — event representations and input processing (future).
- `signals/` — structured signal/silence outputs and learned components (future).
- `training/` — explicit research training loops (future).
- `evaluation/` — evaluation code for detection, temporal, and efficiency metrics (future).
- `runtime/` — future runtime boundary, not a production server.

Do not implement model components in this foundation phase.
