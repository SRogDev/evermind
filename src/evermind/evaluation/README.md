# `evaluation/`

Future home of evaluation code: detection quality (precision/recall/F1,
false alarms), temporal behavior (detection delay, degradation over
long sessions), and efficiency (state size over time, latency, cost per
million events). See `docs/research/evaluation-plan.md`.

**Not implemented.** No benchmarks or thresholds exist yet; thresholds
require approval after the first domain and data strategy are selected.
